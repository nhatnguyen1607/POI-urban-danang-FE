# Danang UrbanAgent AI - Frontend

Frontend React/Vite cho Danang UrbanAgent AI.

## Cau truc chinh

```text
src/pages/dashboard/   Dashboard tong quan
src/pages/traveler/    Role khach/nguoi di choi
src/pages/business/    Role nguoi kinh doanh (se them trong update lon)
src/pages/search/      Tim kiem/semantic query
src/pages/analytics/   Metrics, t-SNE, model reports
src/components/        Component dung chung
src/utils/             API client/helper
public/                Icons/static assets
```

## Chay local

```bash
npm install
npm run dev
```
